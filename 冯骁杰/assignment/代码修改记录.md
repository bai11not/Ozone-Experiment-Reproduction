**修改点④ — 缺失统计函数（第 170-185 行）**

```python
def compute_missing_stats(df, name):
    """计算每个污染物的缺失统计"""
    total = df.size
    missing = df.isnull().sum().sum()
    missing_pct = missing / total * 100
    per_station_missing = df.isnull().sum() / len(df) * 100

    return {
        'name': name,
        'total_values': total,
        'missing_values': int(missing),
        'missing_pct': round(missing_pct, 2),
        'per_station_missing': per_station_missing,
        'stations_above_50pct_missing': int((per_station_missing > 50).sum()),
        'stations_above_20pct_missing': int((per_station_missing > 20).sum()),
        'stations_complete': int((per_station_missing == 0).sum()),
    }
```

### 2.2 `train_air_n95.py` — DiffSTG 适配训练脚本

**文件路径**: `external_baselines/DiffSTG/train_air_n95.py`

**操作类型**: **修改**（基于 DiffSTG 原版 `train.py`）

**修改原因**: DiffSTG 原代码将 T_p 硬绑定为 T_h，无法支持本项目 T_h=24, T_p=6 的标准配置。需解耦两个参数并在 UGnet 架构中支持非对称输入/输出。

#### 五项适配操作及其设计原因

**适配 1 — 格式转换：生成 flow.npy**

```python
# data.npy 原始维度: (95, 8717) — 站点×时间
# DiffSTG 要求格式: (T, V, F) — 时间×节点×特征
# 操作：转置 + 增加特征维
o3_data = np.load('data.npy')          # (95, 8717)
o3_data = o3_data.T                     # → (8717, 95)
o3_data = o3_data[..., np.newaxis]     # → (8717, 95, 1)
np.save('flow.npy', o3_data)
```

**设计原因**: DiffSTG 的数据加载器按 `(T, V, F)` 维度读取，F=1 表示当前仅使用 O₃ 单一目标变量（14 类气象因子暂未纳入，DiffSTG 原生不直接支持多特征输入，属于后续改进方向）。

**适配 2 — 空间图构建：高斯核距离邻接矩阵**

使用 Haversine 公式计算站间球面距离，经高斯核 `A_ij = exp(-d_ij² / (2σ²))` 转化为相似度权重，生成 (95, 95) 邻接矩阵，非零占比 36.3%。

**设计原因**:
- 方法一致：DiffSTG 论文对空气质量数据集明确说明"使用站点距离构建空间相关矩阵"
- 高斯核平滑映射：距离越近 → 权重接近 1 → 信息传递越强
- 36.3% 稀疏度物理合理：O₃ 是区域性污染物，城市群内站点间存在显著空间相关性

**适配 3 — 备选图结构：皮尔逊相关邻接矩阵**

计算每对站点全年 O₃ 序列的皮尔逊相关系数，阈值 |r| ≥ 0.5 过滤，结果矩阵非零占比仅 1.1%。

**设计原因**:
- 弥补距离图的固有缺陷：距离图假设"空间近=功能相关"，但 O₃ 传输受风向、地形影响
- 1.1% 超低稀疏度意味着 95 站 4465 对关系中仅约 49 对呈现强同步——这些极可能是关键传输路径
- 提供实验对比维度

**适配 4 — 时序切分对齐**

| 集合 | 索引范围 | 步数 | 日历范围 |
|------|----------|:---:|------|
| Train | 0 – 7377 | 7378 | 2022-01-01 00:00 至 2022-11-05 23:00 |
| Valid | 7378 – 8046 | 669 | 2022-11-06 00:00 至 2022-12-03 21:00 |
| Test | 8047 – 8716 | 670 | 2022-12-03 22:00 至 2022-12-31 23:00 |

**设计原因**:
- no-leak 是时序预测底线：测试集必须全部在训练集之后
- 与 PE-DiffWaveNet 切分点完全一致：确保指标可直接对比
- 测试集落在 12 月（冬季 O₃ 低谷），对模型是挑战性场景

**适配 5 — 核心：T_h / T_p 解耦**

UGnet 的 U-Net 结构沿时间轴做对称的下采样和上采样，隐含假设输入输出维度相等，因此原生代码将 T_p 硬绑定为 T_h。

方案 B 的具体改动：
1. **掩码逻辑**：原掩码将后 T_h 步置零（因 T_p=T_h），改为掩掉后 T_p 步，支持任意 T_p
2. **UGnet 上采样路径**：末层恢复到 T_p 步即停止，不再强制恢复到 T_h 步
3. **损失计算**：仅在目标 T_p 步上计算去噪损失
4. **命令行参数**：新增独立 `--T_p` 参数，与 `--T_h` 解耦

#### 报告核心内容

**第 1 章 — 模型原理**（约 120 行）：

详细阐述了三模块架构的数学原理和物理直觉：
- **扩散模块**：前向加噪过程 `x_p^n = sqrt(ᾱ_n) × x_p⁰ + sqrt(1-ᾱ_n) × ε`，反向去噪训练目标 `L = E[||ε - ε_θ(...)||²]`，训练同时在历史和未来部分计算损失
- **PE 图**：排列熵计算过程（Bandt & Pompe, 2002 PRL），PE 值含义（低 PE=规律=易预测, 高 PE=复杂=难预测），PE 图构建 `A_PE(i,j) = exp(-|PE_i - PE_j|² / (2σ²))`
- **PE-FiLM**：FiLM 核心公式 `FiLM(特征) = γ × 特征 + β`，γ/β 由 PE 特征经 MLP 动态生成，实现站点自适应处理

三图对比：

| 图 | 非零元素 | 构建方法 | 物理含义 |
|------|:---:|------|------|
| S 矩阵 | 691 | 站点经纬度距离 | "这两个站点空间上很近" |
| T 矩阵 | 1570 | O₃ 时间序列皮尔逊相关 | "这两个站点 O₃ 变化同步" |
| PE 矩阵 | 317 | PE 特征相似度 | "这两个站点的复杂度相似" |

**第 2 章 — 数据准备与图构建**：15 个输入特征（1 目标 + 14 气象），no-leak 三集合切分详情，三图并行构建过程。

**第 3 章 — Smoke Test 运行验证**：完整命令、配置解析、18 个输出文件逐项验证。

**第 4 章 — 正式实验流程**：四大阶段（Smoke → 主实验 → 变体 → 消融），每个实验的目的、命令、预分析。

**第 5 章 — 输出验证清单**：10 项检查 + 5 个核心指标说明 + 预期指标范围。

**第 6 章 — 环境依赖**。

#### 关键洞察

报告中体现了对实验设计的深入思考：

- **为什么需要 3 个 seed**："消除随机性、学术论文标准做法、可复现性。3 个 seed 足以估计方差而不消耗过多 GPU 资源"
- **为什么 seq_len 不是越大越好**："24 小时覆盖完整日周期，48 小时引入两天前的数据，相关性可能已衰减到接近随机水平，徒增计算开销"
- **PE shuffle 是最干净的对照实验**："它不改变模型结构和参数量，只改变 PE 特征与站点的对应关系"
