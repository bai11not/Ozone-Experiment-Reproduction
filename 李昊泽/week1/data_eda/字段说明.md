# data_eda 文件夹字段说明

## data_card.json — 数据卡

中英文双语数据卡，包含完整的数据元信息：

| 字段 | 说明 |
|------|------|
| 项目名称 | 基于PE-DiffWaveNet的多站点臭氧预测 |
| 数据来源 | 2022年全国95个空气质量监测站点逐小时数据 |
| 空间信息 | 95站、编号范围1001A~3699A、含经纬度 |
| 时间信息 | 2022全年、8717小时、逐小时频率 |
| 特征信息 | 15特征 = O3 + 14个ERA5气象再分析因子（含中英文对照表） |
| 缺失值统计 | O3处理数据缺失率0%，原始CSV中约2000站缺失率见pm_stats_report.txt |
| 数据切分 | No-leak协议：时间轴切分→各自滑窗→训练段单独拟合并归一化 |
| 输入输出 | 24小时输入 → 6小时预测 |

## pm_stats_report.txt — PM2.5/PM10缺失统计

遍历全部365个CSV文件（约2000+个站点）的完整统计结果：
- PM2.5 缺失率: 18.27%
- PM10 缺失率: 17.84%
- O3 缺失率: 17.75%（原始CSV中；处理后95站点为0%）
