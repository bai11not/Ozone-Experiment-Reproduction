# Smoke Test 输出字段说明

## config.json — 运行配置参数

| 字段 | 中文说明 | Smoke Test 值 |
|------|----------|:---:|
| train_rate | 训练集占时间轴比例 | 0.8465 |
| seq_len | 输入历史窗口 (小时) | 24 |
| pre_len | 预测步长 (小时) | 6 |
| batch_size | 每批训练样本数 | 2 |
| hidden_size | 模型隐藏层维度 | 16 |
| epochs | 训练轮数 | 1 |
| lr | AdamW初始学习率 | 0.0007 |
| diff_steps | 扩散过程总步数 | 3 |
| use_diffusion | 是否使用扩散精炼 (1=是) | 1 |
| use_pe_graph | 是否使用PE图 (1=是) | 1 |
| use_pe_film | 是否使用PE-FiLM调制 (1=是) | 1 |
| max_train_windows | 训练窗口数上限 (0=不限制) | 8 |
| device | 训练设备 (cpu/cuda) | cpu |

## metrics_summary.json — 评估指标

| 字段 | 中文说明 | Smoke Test 值 |
|------|----------|:---:|
| best_epoch | 验证集最佳轮次 | 1 |
| best_valid_rmse | 最佳验证RMSE | 171.98 |
| test_rmse | 测试集RMSE | 166.85 |
| test_mae | 测试集MAE | 164.74 |
| test_mape | 测试集MAPE (%) | 848.31% |
| relative_rmse | RMSE / O3最大值 (%) | 40.69% |

> 注：Smoke Test 仅跑1轮极小配置，指标无参考意义，仅验证流程正常。

## split_summary.json — 数据切分信息

| 字段 | 中文说明 |
|------|----------|
| time_slices.train | 训练段时间范围 |
| time_slices.valid | 验证段时间范围 |
| time_slices.test | 测试段时间范围 |
| train_windows | 训练窗口数 |
| valid_windows | 验证窗口数 |
| test_windows | 测试窗口数 |

## graph_summary.json — 图结构信息

| 字段 | 中文说明 | Smoke值 |
|------|----------|:---:|
| pe_source | PE特征来源 (train=从训练段计算) | train |
| pe_main_result_safe | 是否可作主结果报告 | true |
| S_nnz | 空间距离图非零边数 | 691 |
| T_nnz | 时间相关图非零边数 | 1570 |
| PE_nnz | 排列熵图非零边数 | 317 |
| use_pe_graph | PE图开关 | 1 |
| use_pe_film | PE-FiLM开关 | 1 |
| pe_graph_alpha | PE图强度系数 | 1.0 |
| pe_film_scale | PE-FiLM调制强度 | 1.0 |
