# 3-Epoch 训练输出字段说明

## config.json — 运行配置

与 Smoke Test 相比的主要区别：

| 参数 | Smoke Test | 3-Epoch | 说明 |
|------|:---:|:---:|------|
| epochs | 1 | **3** | 训练3轮，观察loss下降趋势 |
| hidden_size | 16 | **32** | 隐藏层扩到32 |
| batch_size | 2 | **4** | 每批4条 |
| diff_steps | 3 | **5** | 扩散步数略增 |
| max_train_windows | 8 | **128** | 训练窗口扩到128 |
| save_predictions | 0 | **1** | 保存预测值，可画散点图 |

## metrics_summary.json — 评估指标

| 字段 | 中文说明 | 值 |
|------|----------|:---:|
| best_epoch | 验证集最佳轮次 | 2 |
| best_valid_rmse | 最佳验证RMSE | 159.24 |
| test_rmse | 测试集RMSE | 156.72 |
| test_mae | 测试集MAE | 154.75 |
| test_mape | 测试集MAPE | 727.75% |
| per_step_rmse | 逐步(1-6h)RMSE | [162,160,153,153,151,161] |
| step4_6_rmse_avg | 第4-6步RMSE均值 | 154.95 |
| peak_mode | 峰值检测模式 | percentile |
| peak_threshold | 峰值阈值 (μg/m³) | 64.0 |
| rmse_peak | 峰值区RMSE | 119.33 |
| relative_rmse | 相对RMSE (%) | 38.22% |

## 训练趋势

```
Epoch  | Train Loss | Val RMSE | 趋势
-------|------------|----------|-----
1      | 3.634      | 185.88   | 初始
2      | 2.024      | 159.24   | ↓ 下降
3      | 0.633      | 161.02   | ↓ Loss持续下降
```

Loss 从 3.63 降至 0.63，模型正在学习。RMSE仍高达156，因为仅3轮、32隐藏层、128窗口——远未收敛。正式120轮、64隐藏层、全量数据后RMSE可降至~10.94。

## train_loss.npy / valid_rmse.npy / valid_mae.npy

训练过程中每个epoch记录的：训练损失、验证RMSE、验证MAE。可用 `view_results.py` 绘制曲线。
