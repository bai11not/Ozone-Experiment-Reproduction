## 一、output/ 目录

### 1.1 unified_results_table.csv

**格式**: CSV

**说明**: 所有实验方法的统一结果汇总表

**字段说明**:

| 字段 | 说明 |
|------|------|
| Method | 方法名称 |
| RMSE | 均方根误差（μg/m³） |
| MAE | 平均绝对误差（μg/m³） |
| MAPE | 平均绝对百分比误差（%） |
| Peak_RMSE | 峰值时刻 RMSE（μg/m³） |
| Step6_RMSE | 第6步预测 RMSE（μg/m³） |
| Source | 数据来源 |
| Category | 方法类别 |

**当前包含方法**:

| 类别 | 方法 |
|------|------|
| Main Table | MTGNN, Graph WaveNet, AGCRN, DCRNN, ATGCN-PE3, PE-DiffWaveNet |
| Baseline | Persistence, Historical Mean, GRU, Linear Regression |
| DiffSTG | DiffSTG (smoke), DiffSTG (full) |
| PE-DiffWaveNet | PE-DiffWaveNet (smoke) |

### 1.2 metrics_template.csv

**格式**: CSV

**说明**: 指标记录模板，用于新增实验结果时填写

### 1.3 chart_naming_convention.md

**格式**: Markdown

**说明**: 图表命名规范文档，定义了图表文件的命名格式、类别和缩写规则

### 1.4 paper_assets_summary.json / paper_assets_summary.md

**格式**: JSON / Markdown

**说明**: Paper Assets 字段整理，包含 Table 1/2/3 的字段定义和说明

## 三、DiffSTG/ 目录

### 3.1 概述

DiffSTG（Diffusion-based Spatio-Temporal Graph forecasting）是一种基于扩散模型的概率时空图预测方法。

### 3.2 metrics/DiffSTG.csv

**格式**: CSV

**说明**: DiffSTG 实验测试指标汇总

**字段**: data.name, model, model.N, model.d_h, model.T_h, model.T_p, model.sample_strategy, model.sample_steps, model.beta_end, n_samples, epoch, best_epoch, batch_size, lr, wd, early_stop, is_test, log_time, mae, rmse, mape, crps, mis, time, model_path, log_path, forecast_path

**当前实验**:

| 实验 | d_h | N | batch_size | lr | MAE (norm) | RMSE (norm) | MAE (μg/m³) | RMSE (μg/m³) |
|------|-----|-----|-----------|-----|-----------|------------|-------------|--------------|
| Smoke Test | 16 | 50 | 4 | 0.002 | 0.1464 | 0.1681 | 14.64 | 16.81 |
| Full Train | 32 | 200 | 32 | 0.0001 | 0.4632 | 0.5258 | 46.32 | 52.58 |

### 3.3 log/ 目录

**文件**:

| 文件 | 实验类型 | 内容 |

**文件**:

| 文件 | 实验类型 | 说明 |

| `UGnet+16+50+...+0.002+4.pkl` | Smoke Test | 测试集预测结果 |

### 3.6 重要说明

- 当前训练只运行了 **2个 epoch**（因 `--is_test True` 参数）
- MAE/RMSE 为归一化值，需乘以 max_value=100 转换为真实 μg/m³
- MAPE 值较大（>1000%）是因为数据包含接近0的值

## 六、方法对比总览

### 6.1 当前结果（真实 μg/m³）

| Method | RMSE | MAE | MAPE | Category |
|--------|------|-----|------|----------|
| MTGNN (L=24) | 10.66 | 7.34 | 30.0% | Main Table |
| MTGNN (L=12) | 10.80 | 7.35 | 30.5% | Main Table |
| Graph WaveNet | 11.54 | 7.80 | 33.6% | Main Table |
| AGCRN | 11.69 | 8.21 | 34.8% | Main Table |
| DCRNN | 12.28 | 8.51 | 36.5% | Main Table |
| ATGCN-PE3 | 11.89 | 8.60 | 35.5% | Main Table |
| PE-DiffWaveNet (ours) | 10.94 | 7.56 | 30.8% | Main Table |
| Persistence | 4.76 | 3.18 | 95.1% | Baseline |
| Historical Mean | 5.82 | 4.65 | 189.4% | Baseline |
| GRU Baseline | 3.48 | 2.57 | 92.7% | Baseline |
| Linear Regression | 4.62 | 3.53 | 132.9% | Baseline |
| DiffSTG (smoke) | 16.81 | 14.64 | 1038.7% | DiffSTG |
| DiffSTG (full) | 52.58 | 46.32 | 2785.4% | DiffSTG |
| PE-DiffWaveNet (smoke) | 166.68 | 164.56 | 847.5% | PE-DiffWaveNet |

### 6.2 注意事项

- **Persistence 和 GRU Baseline 表现异常好**：可能是因为使用了较短的历史序列（L=12）或数据划分方式不同
- **DiffSTG 和 PE-DiffWaveNet smoke test 结果较差**：因为训练不充分（仅1-2个 epoch）
- **MAPE 不适用**：数据包含接近0的值，导致百分比误差放大，建议使用 MAE/RMSE 作为主要评估指标
