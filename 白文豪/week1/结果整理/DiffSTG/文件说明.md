# DiffSTG 训练结果文件说明

## 目录结构

```
DiffSTG/
├── metrics/          # 指标结果文件
├── log/              # 训练日志文件
├── model/            # 模型权重文件
├── forecast/         # 预测结果文件
└── 文件说明.md       # 本文档
```

## 一、metrics/ 目录

### 1.1 DiffSTG.csv

**格式**: CSV

**说明**: 包含所有实验的测试指标汇总表

**字段说明**:

| 字段 | 说明 |
|------|------|
| data.name | 数据集名称（AIR_N95） |
| model | 模型类型（UGnet） |
| model.N | 扩散步数 |
| model.d_h | 隐藏层维度 |
| model.T_h | 历史时间步长（输入序列长度） |
| model.T_p | 预测时间步长（输出序列长度） |
| model.sample_strategy | 采样策略（ddpm/ddim_multi） |
| model.sample_steps | 采样步数 |
| model.beta_end | 扩散噪声方差终点 |
| n_samples | 预测样本数（用于集成预测） |
| batch_size | 批大小 |
| lr | 学习率 |
| mae | 平均绝对误差（归一化 scale） |
| rmse | 均方根误差（归一化 scale） |
| mape | 平均绝对百分比误差 |
| crps | 连续排名概率评分 |
| mis | 区间预测分数 |
| time | 测试耗时（秒） |
| model_path | 模型权重路径 |
| log_path | 训练日志路径 |
| forecast_path | 预测结果路径 |

## 二、log/ 目录

### 2.1 格式说明

日志文件名格式：
```
{model}+{d_h}+{N}+{beta_schedule}+{beta_end}+{sample_steps}+{sample_strategy}+{T_h}+{T_p}+{n_samples}+{is_label_condition}+{data.name}+{mask_ratio}+{is_test}+{use_nni}+{lr}+{batch_size}.log
```

### 2.2 文件列表

| 文件 | 实验类型 | 内容 |
|------|----------|------|
| `UGnet+16+50+quad+0.1+50+ddpm+24+6+8+True+AIR_N95+0.0+True+False+0.002+4.log` | Smoke Test | 完整训练日志（配置、模型结构、训练过程） |
| `UGnet+32+200+quad+0.1+200+ddpm+24+6+8+True+AIR_N95+0.0+True+False+0.0001+32.log` | Full Train | 完整训练日志（配置、模型结构、训练过程） |
| `[AIR_N95]mae   0.15+...+.log` | Smoke Test | 测试阶段日志（含最终指标） |
| `[AIR_N95]mae   0.46+...+.log` | Full Train | 测试阶段日志（含最终指标） |

### 2.3 日志内容解读

日志包含以下关键信息：

1. **配置参数**: 所有超参数的完整列表
2. **模型结构**: UGnet 的完整网络架构
3. **训练进度表**:
   ```
   Epoch | Loss  Time | MAE     RMSE    |  MAE    RMSE   Time
      0.0| 10.349 1.6s |[2.62   4.49   ] | 2.50   4.35   39.32s
   ```
4. **测试结果**: 最终测试集指标

### 4.2 文件列表

| 文件 | 实验类型 | 内容 |
|------|----------|------|
| `UGnet+16+50+...+0.002+4.pkl` | Smoke Test | 测试集预测结果（8个样本） |
| `UGnet+32+200+...+0.0001+32.pkl` | Full Train | 测试集预测结果（8个样本） |

### 4.3 预测结果说明

- **格式**: Python Pickle 文件
- **内容**: 包含测试集所有样本的预测结果（多样本集成）
- **数据结构**: 通常为字典或数组，包含 `pred`（预测值）和 `target`（真实值）
- **样本数**: n_samples=8，即每个时间步生成8个预测样本，最终取均值

## 六、重要说明

### 6.1 训练不完整问题

当前训练只运行了 **2个 epoch** 就停止，原因是命令中包含了 `--is_test True` 参数，导致训练完成后立即进行测试并退出。如需完整训练（300个 epoch），需去掉该参数重新运行。

### 6.2 指标转换

DiffSTG 输出的 MAE/RMSE 为归一化 scale，需乘以 `max_value=100` 转换为真实 μg/m³ 单位。

### 6.3 MAPE 异常

MAPE 值较大（>1000%）是因为数据中包含接近0的值，导致百分比误差放大，该指标在本数据上不适用。

### 6.4 数据预处理

数据预处理步骤：
1. 从 `data_combined_m15.npy` 提取 O3 特征（第1个通道）
2. 使用 `nan_to_num` 处理缺失值（填充为0）
3. 构建基于空间距离的高斯核邻接矩阵（σ=50km，阈值=150km）
