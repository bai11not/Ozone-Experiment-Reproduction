## 8. Person C 最终结论

1. **pre_len 是主导因素**：p=3 在所有配置和种子下显著优于 p=6，RMSE 低 2.0-5.2
2. **扩散模型在长预测步上可能适得其反**：p=6 时 no_diff 在两个种子下均优于 full，扩散模型引入的噪声可能超过其收益
3. **l=24 一致优于 l=12**：尤其在 p=6 和 full 配置下，改善可达 0.2-2.0 RMSE
4. **种子稳定性总体良好**：7/8 配置 ΔRMSE < 1.0。C09（full/l=12/p=6/s62）异常，建议重跑
5. **全局最佳**：C12（s62, full, l=24, p=3, RMSE=8.56）
